Configuración requerida

Para conectar tu cuenta de Google real a través de la API oficial:

  1. Ingresa a Google Cloud Console.
  2. Crea un ID de cliente de OAuth 2.0 (tipo Aplicación web).
  3. Agrega en Orígenes autorizados de JavaScript: http://localhost:4200.
  4. Copia tu Client ID y pégalo en backend/.env: 
    GOOGLE_CLIENT_ID=tu-id.apps.googleusercontent.com
  5. Reinicia el backend y el botón oficial de Google aparecerá aquí automáticamente.
